# Velarix Valuation Skill (adaptador para Claude Code)

La especificación canónica e independiente del proveedor está en
`docs/skill/VELARIX-VALUATION-SKILL.md`. **Léela completa antes de actuar**: este
archivo no duplica sus reglas.

Recordatorio mínimo:

1. Lee `docs/00-home.md` y el case MOC activo (`docs/cases/<caso>/00-case-home.md`).
2. La metodología canónica (`docs/velarix-v5/04-VALUATION-METHODOLOGY-V5.md`) manda sobre el código.
3. Evidence ≠ Judgment ≠ Calculation. Nunca apruebes supuestos en silencio, nunca te saltes el preflight y nunca inventes evidencia.
4. `docs/velarix/` y `Negocio*.md` son históricos (`docs/99-archive.md`).
5. Velarix es una herramienta personal: no propongas nada comercial.
